# ✨ Modern AI Assistant with PDF Q&A

A sleek, responsive, and fully functional AI chatbot built using **Python**, **Streamlit**, and the **Google Gemini API**. This assistant not only engages in natural conversations but also has the ability to read and analyze uploaded PDF documents to answer context-specific questions.

## 🚀 Features

* **Conversational AI:** Powered by Google's `gemini-2.5-flash` model for fast and accurate responses.
* **Document Analysis (RAG):** Upload any text-based PDF document, and the AI will read the content to answer your questions based *only* on that document.
* **Smooth Streaming Effect:** Real-time typing effect similar to ChatGPT for a seamless user experience.
* **Context Memory:** The chatbot remembers the conversation history during the session.
* **Modern UI:** Clean, custom-styled interface with user and assistant avatars.

## 🛠️ Tech Stack

* **Language:** Python 3.x
* **Frontend Framework:** Streamlit
* **AI Model:** Google Generative AI (Gemini 2.5 Flash)
* **PDF Processing:** PyPDF2
* **Environment Management:** python-dotenv
